🔥 Firebase Setup Guide

One-time setup for the Deuce & Smash club management system. Takes about 10 minutes.

Step 1 — Create your Firebase project

Step 1

Create project on Firebase Console

  • Go to console.firebase.google.com
  • Click Create a project
  • Name it deuceandsmash-club
  • Disable Google Analytics (not needed)
  • Click Create project
Step 2

Create Realtime Database

  • In the left sidebar → Build → Realtime Database
  • Click Create Database
  • Choose location: asia-south1 (Mumbai) for best latency from Pune
  • Select Start in test mode (you'll add rules in step 4)
Step 3

Get your web app config

  • In Project Overview → click the web icon </>
  • Register app name: deuceandsmash-web
  • Don't enable Firebase Hosting
  • Copy the firebaseConfig object
Step 4

Set Database Security Rules

In Realtime Database → Rules tab, paste these rules:

{
  "rules": {
    "members": {
      ".read": false,
      ".write": false
    },
    "tournaments": {
      ".read": true,
      ".write": false,
      "$tournamentId": {
        ".read": true,
        ".write": true
      }
    },
    "openPlaySessions": {
      ".read": false,
      ".write": false
    },
    "openPlayMatches": {
      ".read": false,
      ".write": false
    },
    ".read": false,
    ".write": false
  }
}

This lets the public scoreboard read tournaments, while members and match data stay private (admin only via the pages which use your config key directly).

Step 5

Import your member database

In Realtime Database → Data tab → click the 3-dot menu → Import JSON → upload firebase-import.json

Step 6 — Paste your config into the pages

Step 6

Generate config snippet

Files to update

Replace the FIREBASE_CONFIG block in these 3 files with your values:

  • members/index.html — member database portal
  • tournaments/admin.html — tournament admin
  • tournaments/scoreboard.html — live public scoreboard

Deploy to Vercel

Final step

Push to GitHub → auto-deploys to Vercel

git add .
git commit -m "Add club management system — members, tournaments, scoreboard"
git push

Vercel auto-deploys on every push. Your pages will be live at:

  • deuceandsmash.com/members/
  • deuceandsmash.com/tournaments/admin.html
  • deuceandsmash.com/tournaments/scoreboard.html
